* **📈 커버리지 대폭 확대**: 방어력 미검증 고가 단지를 가성비로 보완하여 **추천 가능 동네 비율을 47% ➔ 71%로 대폭 확충!**

## 2. 방어력 + 가성비 통합안 (추천 가능 동네 47% ➔ 71% 확대)

12억 초과 고가 아파트 동네일수록 최근 신고가를 기록한 신축 단지가 많아 하락기 회복 이력(방어력) 데이터가 부족했던 빈틈을 **[가성비 대체 알고리즘]**으로 해결하여 실데이터 커버리지를 폭발적으로 늘렸습니다.

```
                  [전체 506개 분석 동네·구간 커버리지 변화]

       [기존 (방어력만 사용)] : 47.0% (238개 동네 추천 가능)
                                  │
                                  ▼  (가성비 대체 보완 적용)
       [통합안 (방어력+가성비)] : 71.0% (359개 동네 추천 가능) 🚀 +24.0%p 확대!
```

## 3. 안정성 지표 출처 분리 명시 (실측 vs 대체)

데이터 신뢰도를 위해 대시보드와 보고서에 **안정성 점수 출처**를 명확하게 2가지로 구분하여 태깅했습니다.

1. **`안정성 출처: 방어력(실측)`**: 당산동(-12.0%), 대방동(-10.2%)처럼 실제 금리 하락장 회복 이력이 검증된 동네 ➔ **[가격 방어율 점수]** 100% 사용
2. **`안정성 출처: 가성비(대체)`**: 12억 초과 신축 단지 등 방어 이력이 미검증된 동네 ➔ **[예산 대비 저렴한 비율 % 점수]**로 자동 대체 사용
