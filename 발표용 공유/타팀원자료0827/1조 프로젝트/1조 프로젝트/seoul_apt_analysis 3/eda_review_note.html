STEP 01

이 데이터가 무엇인가

1행 = 법정동 1개 × 분기 1개. 아파트 실거래 234,485건을 법정동·분기별로 집계해 가격 지표를 만들고, 거기에 상권분석서비스의 상주·유동·직장 인구를 면적 비례로 배분해 붙였다. 조인 키는 법정동코드 8자리(코드8)와 분기.

331 × 21 = 6,951이어야 하는데 실제는 5,672행이다. 거래가 없던 동·분기는 행 자체가 없는 불균형 패널이라는 뜻이고, 이 성질이 뒤에서 결측 해석과 그룹 평균 계산 모두에 영향을 준다.

데이터 계보

실거래가 소스 경계는 계약분기 20241. 서울시 파일은 접수연도 기준이라 2024년 파일에 2023년 계약분이 섞여 있어서, 연도로 중복제거하면 국토부 2023년치 35,582건이 통째로 사라진다. 반드시 분기로 잘라야 한다.

STEP 03

결측치와 중복 — 겉과 속이 다른 경우

결측은 13개 컬럼의 2행뿐. 전체 셀 311,960칸 중 26칸(0.0083%)이고, 전부 유동인구 계열에서 같은 두 행에 몰려 있다 (서초구 내곡동 20231·20234). 나머지 42개 컬럼은 결측 0. 임의로 채우지 않았다.

완전중복 행은 0건. 키 코드8+분기도 5,672개가 모두 유일해서 패널 키로 안전하다.

여기가 핵심

결측률 0.008%는 착시다. 진짜 빠진 값은 331×21=6,951칸 중 1,279칸(18.4%)이고, 이게 NaN이 아니라 행 자체의 부재로 나타난다. 종로구는 동당 10.2분기밖에 없다. 결측 함수로는 절대 안 잡힌다.

또 하나 — 법정동명+분기로 키를 잡으면 중복 21건이 생긴다. 신사동이 강남·은평에 각각 있어서다. 조인·groupby·피벗에는 반드시 코드8을 쓴다.

  • 분포는 단봉 우편향. 평균 1,421 > 중위수 1,284, 평균 미만 59.4%. 이상치는 위쪽에만 199건(3.5%), 아래쪽 0건 → 로그 변환 필요.
  • 구 간 격차 3.2배(강남 2,509 / 도봉 784)보다 구 내부 격차가 더 중요한 변수. 서초구 +347(8개 동 중 반포·잠원 쏠림)이 최대, 성동구 −3.1이 최소.
  • 순위 왜곡 원인은 그룹 크기가 아니라 집계 단위. n≥113으로 6개 구를 걸러도 상위 3개 불변, 동 단위로 접으면 3위가 용산 → 송파로 바뀜.

막힌 곳 / 답을 내지 못한 질문

  1. 구 평균의 가중 기준을 못 정했다. 행 단위 / 동 단위 / 거래건수 가중 중 무엇이 맞는가? 3위가 이 선택에서 갈린다.
  2. 불균형 패널의 결측 처리. 6,951칸 중 1,279칸(18.4%)이 NaN이 아니라 행 부재로 비어 있다 (종로구는 동당 10.2분기). 결측으로 명시해야 하는가, 거래 없음 = 관측 없음으로 두는가?
  3. 고정효과 추정 불가. 상주·직장인구가 연 1회 갱신이라 21분기 동안 동별 고유값이 3개뿐. 계수가 안 잡히는데 대안이 있는가? (행안부 주민등록 인구통계로 교체하면 월 단위가 되어 풀린다는 가설)

경로는 src/paths.py가 프로젝트 폴더 기준으로 계산하므로 폴더를 어디에 두든 그대로 동작한다. 절대경로를 새로 적지 말고 paths.py 상수를 import할 것.

python -m pip install matplotlib

# 2. Windows에서 한글이 깨지면
set PYTHONUTF8=1
set PYTHONIOENCODING=utf-8

# 3. 분포 그림 (pandas 없이 표준 csv + matplotlib만 사용)
python src/plot_dist.py              # 단가_중앙값 → data/output/figures/
python src/plot_dist.py 인구밀도      # 다른 숫자형 컬럼도 인자로

# 4. 패널을 처음부터 다시 만들 때만 (2~4분, 순서 지킬 것)
python src/build_trdar_bjd_map.py    # 공간중첩 → trdar_bjd_fragments.csv
python src/build_panel.py            # → panel_dong.csv, panel_gu.csv
