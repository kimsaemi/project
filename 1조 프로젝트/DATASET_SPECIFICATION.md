## 4. 데이터 활용 가이드

### 1) Python Pandas 예제
```python
import pandas as pd

# 데이터 로드
df = pd.read_csv("final_recommendation_mart.csv")

# 조건 검색: 전용 59㎡ 9억 이하이면서 강남+여의도 추천점수 상위 5개 동네
filtered = df[df["추정_전용59_가격_억"] <= 9.0]
top5 = filtered.sort_values(by="추천점수_강남_여의도", ascending=False)[
    [
        "자치구명",
        "행정동명",
        "추정_전용59_가격_억",
        "time_to_gbd",
        "time_to_ybd",
        "추천점수_강남_여의도",
    ]
].head(5)
print(top5)
```

### 2) Excel 활용
1. `final_recommendation_mart.csv` 파일을 엑셀로 엽니다.
2. 상단 메뉴에서 `데이터` ➜ `필터`를 적용합니다.
3. `예산구간_전용59` 열에서 희망 예산(예: `6~9억(가성비 패밀리)`)을 선택하고, `종합_3040_추천점수` 열을 `내림차순 정렬`하면 최적 동네 순위를 즉시 확인할 수 있습니다.
