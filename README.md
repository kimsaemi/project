# 프로젝트_3040동네추천

## 📌 프로젝트 소개
3040 맞벌이 부부를 위한 서울시 최적 주거지 및 동네 추천 분석 프로젝트입니다.  
라이프스타일, 예산, 직주근접, 상권 및 아파트/주거 환경 데이터를 종합 분석하여 맞춤형 동네 및 주거지를 추천합니다.

## 🛠️ 주요 분석 및 서비스 내용
- **데이터 분석 & 클러스터링**: 서울시 법정동, 상권, 아파트 실거래가 및 인구 이동 데이터를 활용한 데이터 모델링 및 클러스터링
- **맞춤형 동네 추천**: 예산별(5억~12억 등) 3040 맞벌이 최적 주거지 종합 랭킹 산출
- **대시보드 & 리포트**: Interactive GIS 지도 대시보드, 분석 요약 리포트 및 시각화 자료 제공

## 📁 주요 파일 구성
- `3040_맞벌이_주거지_지도_대시보드.html` : GIS 지도 기반 동네 추천 대시보드
- `3040_맞벌이_주거지_분석_및_모델링_팀공유리포트.html` : 주거지 분석 및 모델링 결과 리포트
- `3040_맞벌이_예산별_서울최적주거지_종합랭킹.csv` : 예산대별 추천 동네 종합 랭킹 데이터
