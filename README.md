# 🏢 3040 맞벌이를 위한 서울 아파트 주거지 지도 대시보드 v3.7

> **3040 맞벌이 부부**를 위한 서울시 506개 법정동 맞춤형 아파트 주거지 지도 대시보드입니다.  
> 직주근접(통근 시간), 가격 방어율, 3040 인구 친화도, 거래 유동성 가중치를 실시간으로 조절하며 나에게 꼭 맞는 동네와 주거지를 탐색할 수 있습니다.

---

## ✨ 핵심 주요 기능

1. **🗺️ 506개 법정동 인터랙티브 지도**
   - 추천 순위에 진입한 법정동 위치에 핀/마커 표출
   - 마커 클릭 시 해당 동네 정보 팝업 및 중심 이동 연동

2. **🎛️ 실시간 가중치 조절 (선형비례 슬라이더)**
   - **통근 편리성**, **가격 방어율**, **3040 친화도**, **거래 유동성** 4개 분야 가중치를 0~100% 실시간 조절
   - 가중치 변경 즉시 실시간 종합 점수 및 랭킹 재계산

3. **🔍 스마트 다중 스크리닝 필터**
   - 동네명/자치구 검색창 (예: 당산, 염창, 공덕)
   - **면적 구간 선택**: 전체, 59㎡급(소형), 84㎡급(국평), 84㎡+(중대형)
   - **예산 구간 선택**: 전체(5~15억), 7억 이하, 7억~9억, 9억~12억, 12억 초과
   - 상단 공간 활용을 위한 **[조건 접기/펼치기] 아코디언 컴포넌트** 적용

4. **📊 상세 분석 패널 (1:1 밀착 리포트)**
   - **3대 업무지구(GBD, YBD, CBD) 평균 소요시간** 표시
   - **평형별(소형/중형/대형) 실거래 시세 비교**
   - **시간대별(출근/퇴근/주말) 및 요일별 이동 비중 프로그레스 바**
   - 3040 인구 비중, 자녀 비중, 낙폭 및 저점 대비 회복률 제공

5. **📱 모바일 & PC 반응형 최적화**
   - 모바일 환경을 고려한 **[📋 리스트 보기 / 🗺️ 지도 보기]** 탭 전환
   - 리스트 스크롤 시 등장하는 **`맨 위로` (TOP) 플로팅 버튼** (상단 탭 가림 방지 120px 임계치 및 `touchstart` 고속 응답 적용)
